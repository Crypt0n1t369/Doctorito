# Atbalsts platform concept

This package defines a high-level architecture, conversational UX and government briefing for an authority-governed community capability network in Latvia.

## Contents

- `docs/ARCHITECTURE.md` — system, trust, context, authority and reliability architecture.
- `docs/UX-SPEC.md` — bilingual citizen and authority interaction model.
- `prototype/index.html` — interactive, dependency-free UX prototype.
- `presentation/` — senior-official briefing and its editable source.

## Prototype

Open `prototype/index.html` in a modern browser. It is a concept demonstration, not an operational emergency service.

## Status

Concept version 0.1. It deliberately excludes live emergency dispatch, medical triage, minors, weapons, cash transfer and hazardous volunteer assignments.
