Cards

A card is a payload that lives on the receiver, not on the air. Broadcast its four-byte code instead and the airtime stops depending on the payload's size at all — 0.55 s per pass in a micro frame, whether the card holds 65 bytes or 60 KB. On a signed channel a 64-byte Ed25519 signature and its key id push the message to 72 bytes, so it needs a standard frame: 1.20 s per pass.
